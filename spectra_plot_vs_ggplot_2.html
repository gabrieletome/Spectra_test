Installation

First we compare how the ggplot/ggiraph dependencies affect the installation of Spectra. To do so, we will do a clean new installation of Spectra in two different folders. The installation with ggplot2 require many more dependencies.

## Prepare the folders
dir.create(lib_base, recursive = TRUE, showWarnings = FALSE)
dir.create(lib_ggplot, recursive = TRUE, showWarnings = FALSE)

benchmark_install <- function(repo, lib_path, label = "") {
    ## Clean downloaded package.
    pak::pak_cleanup(force = TRUE)

    BiocManager::install(version = "devel", update = FALSE, ask = FALSE)
    options(repos = BiocManager::repositories())

    t0 <- Sys.time()
    result <- pak::pkg_install(
        repo,
        lib = lib_path,
        ask = FALSE,
        dependencies = TRUE,
        upgrade = TRUE
    )
    t1 <- Sys.time()

    list(
        label = label,
        time_sec = as.numeric(difftime(t1, t0, units = "secs")),
        installed_pkgs = list.files(lib_path),
        n_pkgs = length(list.files(lib_path))
    )
}

res_base_install <- suppressMessages(benchmark_install("rformassspectrometry/Spectra",
                                        lib_base, label = "Base"))

res_ggplot_install <- suppressMessages(benchmark_install("gabrieletome/Spectra",
                                        lib_ggplot, label = "ggPlot2"))

comparison <- data.frame(
    label = c(res_base_install$label, res_ggplot_install$label),
    time_seconds = c(res_base_install$time_sec, res_ggplot_install$time_sec),
    n_packages_installed = c(res_base_install$n_pkgs, res_ggplot_install$n_pkgs))
print(comparison)
    label time_seconds n_packages_installed
1    Base     808.7645                  118
2 ggPlot2     884.7201                  134

Run the plotting benchmarks

The two Spectra installs (test_env_base/library and test_env_ggplot/library) cannot both be loaded in this same R session. Instead, each half of the benchmark is a separate .qmd file (_bench_base.qmd, _bench_ggplot.qmd), and we render each of them with its own quarto render call. In this way we can compare the correctly the two function.

system2("quarto", c("render", "_bench_base.qmd", "--to", "html"))
system2("quarto", c("render", "_bench_ggplot.qmd", "--to", "html"))

Compare the results: base plot VS ggplot

Each child render saved its microbenchmark result objects to disk (benchmark_plot.Rdata, benchmark_ggplot.Rdata). We load both back into this session to build the final comparison.

For the comparison we will use the same dataset used in the Spectra vignette. The data are loaded in memory using MsBackendMemory(), in this way we will check only the difference between base R plot and ggplot. Later in the vignette a smaller test based on MsBackendMzR() will be conducted.

load("benchmark_plot.Rdata")
load("benchmark_ggplot.Rdata")
  • Each function runs 10 times to obtain a solid results.
